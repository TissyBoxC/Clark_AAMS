# 珂拉课程表用户手册功能总览

适用版本：v1.1.0 build 9  
本文根据当前项目代码整理，用于后续编写正式用户手册。

## 1. 应用定位

珂拉课程表是一款用于查看、导入和维护本学期课程安排的本地课程表应用。应用核心数据保存在本机，支持手动维护课程、通过多种方式导入课程、查看周课表、同步桌面小组件，并提供账号体系和学习通作业辅助功能。

当前应用主要面向 Android 使用场景。桌面小组件功能已接入 Android 原生小组件能力，并针对 ColorOS 的“卡片”入口做了兼容。iOS 侧可使用应用内课表功能，但当前代码中的桌面小组件同步逻辑仅在 Android 平台启用。

## 2. 首次使用

首次打开应用时会进入学校选择页。

### 2.1 选择学校

学校列表由后端实时提供，用户可以按学校名称、简称或学校 ID 搜索。选择学校后，应用会进入课程设置页，引导用户导入或添加课程。

如果所选学校已配置教务系统导入能力，后续可以通过“教务系统导入”读取课表。如果学校暂未配置教务导入，仍然可以使用 OCR、取件码、JSON 或手动添加课程。

### 2.2 使用其他方式导入

如果用户不想选择具体学校，可以点击“使用其他方式导入”。该模式不会绑定具体学校，适合只使用 OCR、取件码、JSON 或手动维护课程的用户。

## 3. 主界面

应用主界面包含三个底部导航入口：首页、课程表、我的。

### 3.1 首页

首页用于快速查看今天的课表状态，主要包括：

- 当前周次。
- 当前课程总数。
- 今天的课程数量。
- 今天每一节课的课程名称、节次、时间范围和上课地点。
- 今天没有课程时显示空状态。
- 可从首页直接跳转到完整课程表。

应用会根据“第一周第一天”自动计算当前周次。如果用户已有课程但还没有配置学期起始日期，应用会提示配置第一周第一天。

### 3.2 课程表

课程表页用于查看完整周课表，主要包括：

- 按周查看课程。
- 支持切换周次，最大周数由应用设置控制。
- 按星期一到星期日展示课程列。
- 按节次展示课程块。
- 课程块使用课程颜色区分。
- 点击课程块可以查看课程详情。

课程详情中会展示：

- 课程名称。
- 上课周次。
- 星期与节次范围。
- 时间范围。
- 教师信息，如果导入数据中包含。
- 原始时间文本，如果导入数据中包含。
- 上课地点。

## 4. 课程导入

课程导入入口位于“我的”里的“课程设置”，点击右上角菜单后选择“导入课程”。

### 4.1 OCR 图片识别导入

OCR 导入用于从课表图片中识别课程。

使用流程：

1. 在课程设置页打开“导入课程”。
2. 选择“使用 OCR 导入”。
3. 从相册中选择一张或多张课表图片。
4. 应用上传图片到后端识别。
5. 识别完成后会生成取件码。
6. 用户可以复制取件码，也可以继续导入识别出的课程。
7. 导入前需要设置第一周第一天和每节课开始时间。
8. 设置课程颜色后确认导入。

注意事项：

- OCR 功能需要网络连接和后端服务可用。
- 识别结果依赖图片清晰度和课表格式。
- 取件码可用于在其他设备或稍后重新获取识别结果。

### 4.2 取件码导入

取件码导入用于通过 8 位取件码获取已识别的课程数据。

使用流程：

1. 在课程设置页打开“导入课程”。
2. 选择“使用取件码导入”。
3. 输入 8 位取件码。
4. 应用从后端读取对应课程。
5. 配置第一周第一天和每节课开始时间。
6. 设置课程颜色后确认导入。

### 4.3 教务系统导入

教务系统导入用于从学校教务系统读取课表。该功能只对已配置教务导入能力的学校开放。

使用流程：

1. 首次使用时选择支持教务导入的学校。
2. 在课程设置页打开“导入课程”。
3. 选择“教务系统导入”。
4. 应用打开学校教务系统登录页。
5. 用户在 WebView 中自行登录教务系统。
6. 应用检测到登录成功后读取登录会话信息。
7. 后端根据学校适配规则拉取并解析课程。
8. 用户配置第一周第一天和每节课开始时间。
9. 设置课程颜色后确认导入。

注意事项：

- 教务系统导入需要学校配置支持。
- 登录过程在学校教务系统页面完成。
- 如果学校登录页、成功跳转规则或教务接口变化，可能需要更新后端适配。

### 4.4 JSON 批量导入

JSON 批量导入用于粘贴课程数组并一次性添加多门课程。

入口：课程设置页右上角菜单，选择“批量添加”。

支持字段包括：

| 字段 | 说明 |
| --- | --- |
| `name` | 课程名称 |
| `startWeek` | 开始周 |
| `endWeek` | 结束周 |
| `dayOfWeek` | 星期，1 到 7 分别表示周一到周日 |
| `startLesson` | 开始节次 |
| `endLesson` | 结束节次 |
| `location` | 上课地点 |
| `teacher` | 教师，选填 |
| `rawTime` | 原始时间文本，选填 |
| `weeks` | 精确上课周，选填，用于单双周或不连续周次 |
| `colorValue` | 课程颜色 ARGB 整数，选填 |

示例：

```json
[
  {
    "name": "高等数学",
    "startWeek": 1,
    "endWeek": 18,
    "dayOfWeek": 1,
    "startLesson": 1,
    "endLesson": 2,
    "location": "A101",
    "teacher": "张三",
    "weeks": [1, 2, 3, 4]
  }
]
```

批量添加窗口还支持“导出 JSON”，会把当前课程以应用可重新导入的 JSON 格式复制到剪贴板。

## 5. 课程管理

课程管理入口位于“我的”里的“课程设置”。

### 5.1 手动添加课程

点击课程设置页右下角的加号按钮可以手动添加课程。

可填写或选择的内容包括：

- 课程名称。
- 开始周和结束周。
- 星期。
- 开始节次和结束节次。
- 上课地点。

保存时会校验课程名称不能为空、开始周不能大于结束周、开始节次不能晚于结束节次。

### 5.2 编辑课程

在课程列表中点击课程卡片右侧菜单，可以编辑课程。编辑时可修改课程名称、周次、星期、节次和地点。

如果课程来自导入数据，教师、原始时间文本等导入字段会在编辑后尽量保留。若修改了周次范围，原有的精确上课周可能会被清空，避免旧数据与新范围冲突。

### 5.3 删除课程

课程设置页支持单门删除和批量删除。

单门删除：在课程卡片菜单中选择删除。  
批量删除：在右上角菜单中选择“批量删除”，勾选课程后确认删除，也可以全选。

删除操作会影响本地课程数据和桌面小组件显示。

### 5.4 课程颜色

每门课程都有颜色。导入课程时应用会按课程名称生成默认颜色，用户也可以在课程菜单中手动更换颜色。

课程颜色会用于：

- 课程设置列表。
- 周课表课程块。
- 课程导入后的颜色确认流程。

## 6. 学期与节次时间

学期时间配置用于计算当前周次。节次开始时间用于显示课程时间范围，也用于桌面小组件判断下一节课。

可配置内容包括：

- 第一周第一天。
- 每一节课的开始时间。
- 最大周数。

配置入口包括：

- 课程导入完成后的引导页。
- 首页检测到缺少学期开始日期时的提示。
- “我的”里的“应用设置”。

如果不配置每节课开始时间，应用内课程仍可以按节次显示，但桌面小组件可能无法判断下一节课，会提示先配置上课时间。

## 7. 应用设置

应用设置入口位于“我的”里的“应用设置”。

当前设置功能包括：

- 查看当前学校信息。
- 重新选择学校。
- 配置第一周第一天。
- 配置每节课开始时间。
- 修改最大周数。
- 重置设置。

修改最大周数时，应用会询问是否同步影响持续整个学期的课程。如果最大周数变小，超过新最大周数的课程范围会被截断。如果最大周数变大，用户可以选择是否把原本覆盖整个旧学期的课程扩展到新的最大周数。

重新选择学校或重置设置会清空本地已保存课程，请在操作前确认是否需要先导出 JSON。

## 8. 桌面小组件与系统卡片

桌面小组件入口位于“我的”里的“桌面小组件”。

当前版本中，点击该入口不会再直接请求系统添加小组件，而是提示“不同系统添加小组件方式不同”，用户可以关闭提示或跳转官网查看手册。

### 8.1 支持的小组件尺寸

当前 Android 侧已注册两类小组件：

- 2x2 小组件：主要显示下一节课。
- 4x2 小组件：主要显示今天前两节相关课程。

在部分系统中，桌面入口可能显示为 3x2、卡片或其他等效尺寸，这是系统桌面根据自身规则映射后的结果。

### 8.2 2x2 小组件显示内容

2x2 小组件适合放在较小桌面区域，优先展示最关键的信息：

- 今天日期和星期。
- 当前周次。
- 下一节课程名称。
- 开始时间。
- 剩余时间或已开始状态。
- 教室信息。如果教室为空，则显示第几节。

如果今天没有课程，会显示今天暂无课程。  
如果今天课程已经全部结束，会随机显示一条“今天课程已结束”类提示。  
如果没有配置节次开始时间，会提示先配置上课时间。

### 8.3 4x2 小组件显示内容

4x2 小组件展示空间更大，主要显示：

- 今天日期和星期。
- 当前周次。
- 今天最多两门课程。
- 每门课的开始时间。
- 课程名称。
- 课程时间、节次或教室信息。

### 8.4 不同系统的小组件添加方式

不同 Android 系统对桌面小组件入口的命名不同，可能显示为“小组件”“卡片”或“插件”。

#### ColorOS

1. 长按桌面空白区域 2 秒，或在桌面使用两指收缩手势。
2. 点击底部的“卡片”。
3. 选择左上角靠下位置的“全部卡片”。
4. 拉到页面最下面，点击“插件”。
5. 在插件列表中找到“珂拉课程表”。
6. 选择需要的组件框大小并添加到桌面。

提醒：在选择页面看到的组件大小可能与实际添加到桌面后的大小不完全一致，系统会根据桌面布局自动适配大小。

## 9. 我的页面

“我的”页面是工具和设置入口，当前包括：

- 账号入口。
- 桌面小组件说明入口。
- 学习通作业辅助。
- 课程设置。
- 应用设置。
- 关于。

顶部个人区域会根据登录状态显示用户信息。未登录时，课程表和桌面小组件仍然可以正常使用。

## 10. 账号功能

账号页支持三种模式：

- QQ 邮箱和密码登录。
- 登录码登录。
- 注册并登录。

注册和邮箱登录要求使用 QQ 邮箱。登录后可以查看：

- 显示名称。
- 邮箱。
- 登录码。
- 邮箱认证状态。
- 做题辅助使用次数。

登录后可以复制登录码，也可以退出登录。

账号主要用于学习通作业辅助等需要后端鉴权的功能。课程表查看、课程维护和桌面小组件不要求登录。

## 11. 学习通作业辅助

学习通作业辅助入口位于“我的”里的“学习通作业辅助”。该功能需要先登录珂拉课程表账号。

功能流程：

1. 应用打开学习通网页。
2. 用户在 WebView 中自行登录学习通。
3. 用户手动进入作业题目页面。
4. 点击悬浮面板中的开始按钮。
5. 应用读取当前页面题目和选项。
6. 应用向后端提交题目分析请求。
7. 后端返回分析结果后，应用尝试提取答案选项。
8. 应用向学习通页面注入点击脚本，尝试选择对应答案。
9. 面板显示题目总数、当前进度、成功数和失败数。
10. 用户可以在处理过程中停止。

注意事项：

- 该功能依赖学习通页面结构，页面结构变化可能导致识别或点击失败。
- 该功能需要网络连接和后端服务可用。
- 用户需要自行登录学习通并进入具体作业页面。
- 若账号登录状态失效，需要重新登录珂拉课程表账号。

## 12. 关于与版本更新

“关于”页面展示应用基础信息，包括：

- 应用图标。
- 应用说明。
- 当前版本。
- 最新版本检查结果。
- 检查更新。
- 手动更新入口。
- 作者信息。
- 开源协议。
- 开源仓库地址。
- QQ 联系方式和交流群。

应用启动后也会检查后端版本信息。如果后端标记为强制更新，应用会显示不可忽略的更新提示。如果是普通更新，用户可以稍后再说或跳转下载页面。

## 13. 数据保存与网络说明

本地保存的数据包括：

- 应用设置。
- 已导入或手动添加的课程。
- 下一课程 ID。
- 桌面小组件展示数据。

账号令牌使用安全存储保存。课程数据主要保存在本机，重新选择学校或重置设置会删除本机课程。

需要网络的功能包括：

- 学校列表加载。
- 学校教务导入配置加载。
- OCR 图片识别。
- 取件码读取。
- 教务系统课程导入。
- 账号注册、登录和刷新。
- 学习通题目分析。
- 版本检查和更新信息获取。

## 14. 常见问题

### 14.1 为什么首页周次不对？

请进入“应用设置”，检查“第一周第一天”是否设置为本学期第 1 周的第一天。当前周次由该日期和系统日期计算。

### 14.2 为什么桌面小组件提示先配置上课时间？

小组件需要每节课开始时间来判断下一节课。如果只导入了课程节次，没有配置节次开始时间，小组件无法计算下一节课。请进入“应用设置”配置每节课开始时间。

### 14.3 为什么今天明明有课，小组件显示没有课程？

可能原因包括：

- 当前日期计算出的周次不在课程周次范围内。
- 课程的星期设置与今天不一致。
- 第一周第一天设置错误。
- 课程使用了精确上课周，但今天所在周不在 `weeks` 列表中。
- 桌面小组件刷新延迟，可以打开应用后等待系统刷新。

### 14.4 为什么 ColorOS 里叫“卡片”而不是“小组件”？

这是系统桌面对小组件入口的命名差异。应用侧注册的是 Android 桌面小组件，ColorOS 可能在桌面、卡片中心或插件中心中展示。

### 14.5 重新选择学校会发生什么？

重新选择学校会清空本地课程，并回到学校选择流程。如果需要保留课程，请先在课程设置页使用“批量添加”里的“导出 JSON”复制当前课程数据。

### 14.6 不登录账号能用课表吗？

可以。课程表、课程管理、课程导入和桌面小组件不强制登录。学习通作业辅助需要登录账号。

### 14.7 教务系统导入失败怎么办？

可以尝试：

1. 确认学校支持教务系统导入。
2. 确认教务系统账号密码可以正常登录。
3. 重新进入教务导入页面登录。
4. 使用 OCR、取件码、JSON 或手动添加作为替代方式。

### 14.8 OCR 识别不准怎么办？

可以尝试：

1. 使用更清晰的课表截图。
2. 避免裁切掉周次、星期、节次或课程地点。
3. 多张图片一起上传。
4. 识别后手动编辑错误课程。
